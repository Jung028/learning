SwipeLearn · working name

Design system

One set of colours, type, shapes and buttons used on every screen. Warm latte background, one mocha action colour with caramel for streaks, a serif for titles and a clean sans for reading. Pill-shaped buttons and soft, rounded cards. Every button below says where it leads.

4. Buttons and controls

Mocha (primary)
One per screen. The next step forward: New module, Generate outline, Start chapter 1, Take quiz, Next chapter.
Secondary
A useful side step: Review cards, Retry missed questions, Regenerate outline.
Text button
Leaves a flow without a new action: Done, Skip, Cancel.
Icon button · 44 × 44
Close, Save card, Back. Always have an accessible label.
Chip: off and selected
Pick one option, stay on the screen: level and number of chapters.
Ask Claude pill
Opens a bottom sheet over the card: Explain simpler, Give an example, Ask a question.
Danger button
Only for actions that cannot be undone. Always opens a confirm sheet first.
Toggle switch: on and off
Instant settings: daily reminder, live discussions. Changes apply at once, no save button.
Hold to speak
Idle and held. Press and hold to talk, release to send. Space bar works too. Sessions are capped at 10 minutes.
